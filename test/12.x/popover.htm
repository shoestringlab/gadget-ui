Popover — 12.3.0 API

1. Default (no anchor) — back-compat mode

No anchor or portal passed. The popover renders at the pre-12.3.0 default position (top: 100px; left: 50%; transform: translateX(-5%)), identical to pre-12.3.0 behavior.

Default popover
No anchor, no portal — uses the CSS placeholder position.

2. Anchor-relative, placement: bottom (default), align: left

JS drives position: fixed from the anchor's rect. Scroll the page — the popover follows.

Anchored: bottom + left
Aligned to the trigger's left edge, below it.

3. Anchor-relative — align: right, placement: top

Anchored: top + right
Aligned to the trigger's right edge, above it.

4. Anchor + portal — escapes overflow:hidden ancestor

The dashed container has overflow: hidden and a transform. Without portal: true the popover would be clipped at the container's edges. With portal mode it mounts on document.body and renders unclipped, still tracking the anchor button's position.

Clipping container

Anchored + portal
Mounted on body, unclipped by the container.

5. Lifecycle events

Each popover above is wired to log opened / closed / removed. The destroy button below tears down the bottom-left anchored popover and fires "removed".
